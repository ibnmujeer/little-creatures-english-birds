# English Birds

A picture-and-sound matching game that helps young children learn the names of birds in English.

## Play

Open `index.html` in a browser, or upload the contents of this folder to a static website. For step-by-step GitHub Pages instructions, see the [publishing guide](../../docs/GITHUB_PAGES_GUIDE.md).

## Keep the files together

Keep `index.html`, the game files, and the `assets` folder together. The game uses the pictures in `assets` and the browser's available English voice for spoken names.
